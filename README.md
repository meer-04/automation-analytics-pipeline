## Overview

This project demonstrates a **realistic enterprise automation workflow** where:

- **Java + Selenium** automates a business process and extracts transactional data
- Extracted data is exported as a **CSV**
- **Python analytics** cleans, analyzes, and visualizes the data
- A **one-page HTML dashboard** is generated for business consumption
- The entire pipeline runs **locally or via CI/CD (GitHub Actions)**

This mirrors how automation outputs are consumed by **analytics and reporting systems** in real organizations.

---
## Execution Details
- Sample command to run the full pipeline locally:
    ```bash
     .\run_pipeline.bat --browser chrome
    ```
- This will execute the Selenium automation, generate the CSV, run the Python analytics, and produce the HTML dashboard in one go.

### Supported Parameters
| Parameter | Description | Default Value |
|-----------|-------------|---------------|
| `browser` | Browser to run tests on (chrome, edge, firefox, safari) | chrome        |
| `headless` | Run browser in headless mode (true/false) | true          |
| `url` | URL of the application under test | NA            |

### Prerequisites For Running Locally (Windows)
- Java 21
- Maven
- Python 3.9.12
- Google Chrome

Open output folder to view Allure reports and `dashboard.html` for final analytics report.

---

## Running via CI/CD (GitHub Actions)

- CI pipeline implemented using GitHub Actions
- Triggered on:
    - Push to `main`
    - Manual trigger (`workflow_dispatch`)

### CI/CD Behavior
- Fresh runner is provisioned
- Java, Maven, Python, and Chrome installed explicitly
- Selenium runs in headless mode
- Python analysis runs automatically
- Entire `outputs/` folder uploaded as a CI artifact

Artifacts
can be downloaded from the GitHub Actions UI.

- Transaction-level data extraction from a sample banking flow
- Structured CSV output for downstream analytics

---

## Analytics Details (Python)

- Reads CSV generated by Selenium automation
- Cleans raw data (currency symbols, dates, null values)
- Computes business metrics:
    - Total credit
    - Total debit
    - Net cash flow
    - Transaction count
- Generates analytical charts:
    - Credit vs Debit comparison
    - Debit trend over time
- Flags high-value transactions
- Produces a single-page HTML dashboard
